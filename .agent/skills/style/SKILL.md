# StudySquad Style

## But

Appliquer une direction visuelle coherent avec StudySquad: sombre, energique, lisible et orientee productivite.

## Quand l'utiliser

- creer ou refondre une page;
- ajouter un composant UI;
- harmoniser les couleurs, espacements ou animations;
- integrer des icones ou des blocs hero/CTA.

## Regles visuelles

- utiliser Tailwind CSS pour la structure et les variantes;
- preferer le duo noir + rouge comme base de marque;
- ajouter des fonds en gradient, des overlays ou des effets de glow avec moderation;
- utiliser Iconify pour les icones;
- utiliser Framer Motion pour les transitions d'entree, les cartes et les appels a l'action;
- garder des contrastes forts et une lecture immediate.

## Principes UI

- une page = une intention principale claire;
- une carte = une information ou une action dominante;
- limiter les effets decoratifs qui nuisent a la comprehension;
- privilegier les composants reutilisables;
- adapter le layout mobile avant d'optimiser le desktop.

## Conventions

- pas de couleurs arbitraires si une couleur de marque existe deja;
- pas de bibliotheque d'animation supplementaire si Framer Motion suffit;
- pas de `any`;
- suivre les types exportes depuis `studysquad/src/types/index.ts`.

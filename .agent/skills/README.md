# Skills StudySquad

Ce dossier regroupe les skills locaux du projet.

## Liste

- `style`: direction visuelle, Tailwind, Iconify, Framer Motion;
- `rules`: contrat de typage, absence de `any`, alignement SQL;
- `architecture`: organisation des couches, services, hooks, pages;
- `debug`: methode de diagnostic et d'isolation des erreurs.

## Usage recommande

- utiliser `style` pour toute evolution d'interface;
- utiliser `rules` avant de creer ou modifier des types;
- utiliser `architecture` avant d'ajouter un nouveau flux metier;
- utiliser `debug` quand un comportement est incoherent avec les donnees ou le rendu.
